AGENTIC AI

AWS-Aware Security Firewall for AI Agents

Developed a two-guard security prototype for AI agents with tool access. The Permission Guard checks identity, role, action and resource authorization. The Reachability Guard evaluates data provenance, sensitivity and potentially unsafe data-flow paths.

Integrated LangGraph orchestration, an MCP gateway, and a Gemini-based planner with local fallback in a simulated AWS environment. A tested scenario blocked a sensitive salary file upload to a public S3 bucket before the upload tool executed.

PRESENTED AT CVR 2026

Multi-Task Deep Learning Framework for Automated Health Anomaly Detection from X-Ray Images

Developed a multi-task framework using an EfficientNet-B3 shared backbone and four task-specific heads on MURA-v1.1: anomaly detection, severity intensity, gender prediction and anomaly description.

Applied weighted random sampling, MixUp regularization and AdamW optimization with cosine annealing.

91.8% anomaly validation accuracy 88.3% severity validation accuracy 94.2% gender validation accuracy 86.1% description validation accuracy

These are validation results. Auxiliary labels were synthetically derived and are not clinically verified.
